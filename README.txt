ChurchCare Luxury Web App v6 — Campus Ministry + Visitor Inviter Tracking

NEW IN VERSION 6
- Every visitor registration now records the name of the person who invited them
- Inviter can be selected from current members or typed manually
- Inviter is shown in the visitor registry, live attendance view, history details, conversion workflow and visitor CSV export
- Visitor inviter information is retained when a visitor is converted into a member
- Added a Settings danger zone with a Delete all site data button
- Full site deletion requires TWO separate confirmation prompts
- Full deletion removes members, visitors, attendance, shepherd assignments, care notes, birthdays and roster records from the current browser
- A backup button is placed beside the delete-all control for safer administration

RETAINED FROM VERSION 5
- Dedicated Visitors page and visitor registry
- Visitors kept separate from church members
- Repeat-visit tracking, first/last visit dates and birthdays
- Campus ministry lifecycle statuses: Current, Completed school, Transferred, Left ministry and Archived
- Non-current members automatically excluded from current attendance, activity classification, shepherd workload and care alerts
- Historical attendance preserved when member roster status changes
- Bulk roster management
- Automatic Active/Inactive classification from attendance
- Shepherd assignment and member-care workflow
- Separate member, visitor and attendance CSV exports
- Full JSON backup and restore

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Data is stored locally in the browser through localStorage.
4. Use Backup Data regularly, especially before bulk roster changes or before using Delete all site data.

IMPORTANT
For students who complete school, use the Completed school status rather than permanent deletion. This removes them from current operational lists but keeps historical attendance.
