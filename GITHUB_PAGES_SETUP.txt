CHURCHCARE — QUICK GITHUB PAGES SETUP

1. Create a GitHub repository, e.g. churchcare.
2. Upload these files directly to the repository root:
   - index.html
   - styles.css
   - app.js
   - .nojekyll
   - README.md
3. Go to repository Settings > Pages.
4. Under Build and deployment, select:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
5. Save.
6. Your live link will look like:
   https://YOUR-USERNAME.github.io/churchcare/

IMPORTANT:
The current app stores data in each browser's local storage. Hosting it on GitHub Pages does not automatically make data shared across phones or laptops.
